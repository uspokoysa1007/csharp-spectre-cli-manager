# csharp-spectre-cli-manager

Интерактивный консольный менеджер задач и системы на C# (.NET 8) с ANSI-палитрами, таблицами и меню навигации стрелками.

## Возможности
- Интерактивное меню со стрелочной навигацией (`↑`, `↓`, `Enter`).
- Просмотр активных процессов Windows с сортировкой по потреблению памяти.
- Инспектор системных дисков и свободного пространства с цветными статус-барами.
- Анимированный спиннер выполнения задач в консоли.
- Полная автономность: работает нативно под Windows.

## Сборка
```bash
dotnet build -c Release -o releases
```

## Использование
```bash
./releases/csharp-spectre-cli-manager.exe
```
